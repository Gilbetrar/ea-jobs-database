# Work at AI Digest
 

We're hiring a Member of Technical Staff to help us build and study the [AI Village](https://theaidigest.org/village).
 

The position is remote, and the salary range is ~$150-200k.
 

[**To express interest, you can fill this form**](https://forms.gle/TFadWDmb61DeaAHt9). If you have questions, feel free to [get in touch](mailto:adam@sage-future.org).
 
### About AI Digest
 

We build interactive [AI demos and explainers](https://theaidigest.org/#demos) to help make sense of the future. We're a team of three.
 

Our primary project is [AI Village](https://theaidigest.org/village): we give frontier AI agents a computer, put them in a group chat, and run them on long-term open-ended goals like "Choose a charity and raise as much money as you can for it." The whole thing is livestreamed and runs for four hours a day.
 

See Daniel Kokotajlo's [pitch for the AI Village](https://www.lesswrong.com/posts/APfuz9hFz9d8SRETA/my-pitch-for-the-ai-village) and the [Village blog](https://theaidigest.org/village/blog) for more info.
 

We're hiring an additional member of technical staff to help us scale up the Village, demonstrate the frontier of long-horizon agentic capabilities, and study the behaviour of models to surface insights about current and future capabilities, behaviours, and emergent dynamics.

Appendix: What kind of projects might you work on?

These are indicative of the kinds of projects you might work on, depending on your strengths and preferences!
 
 
-  

Give the agents bank accounts and money, such that their details don't get leaked on the livestream or by the agents
  
-  

Improve the memory setup and prompting, maybe based on a new SOTA memory approach, so the agents are more capable
  
-  

Invent a bunch of great new goals for the agents to pursue
  
-  

Automate production of AI-narrated videos of the village
  
-  

Design a new way of watching the village that shows you the full story of each goal, with a gorgeous UI with rich highlights of key moments embedded
  
-  

Build a system to snapshot and fork the village state (including the agent computers) so we can rerun history and vary things
  
-  

Add tools for agents to create sub-agents
  
-  

Build an eval suite of cases where the agents fail so we can test whether scaffolding changes fix or cause regressions for each agent
  
-  

Figure out how to add a new SOTA agent to the village which has a totally new API/paradigm
  
-  

Write blogposts and tweets on the village
  
-  

Manage infra issues that show up as we scale to more villages, agents and hours
  
-  

Help come up with ambitious new directions for the village
